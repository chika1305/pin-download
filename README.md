# Pinterest Image Downloader

Программа для скачивания изображений с досок Pinterest с поддержкой автоматического улучшения качества (upscale).

## Возможности

- 📥 **Скачивание изображений** с досок и профилей Pinterest
- 🎯 **Ограничение количества** - скачивание только первых N изображений
- 📁 **Автоматические подпапки** - создание папок по названиям досок
- 🔄 **Продолжение скачивания** - пропуск уже скачанных файлов
- 🎨 **Upscale изображений** - улучшение качества с помощью Real-ESRGAN
- ⏱️ **Оценка времени** - показ оставшегося времени скачивания и upscale
- 📊 **Статистика** - отслеживание найденных, скачанных и пропущенных изображений
- 🔢 **Шаблоны имен файлов** - настройка формата имен скачанных файлов
- 📝 **История скачиваний** - сохранение истории для быстрого доступа

## Требования

- **Python 3.7+**
- **Google Chrome** (для работы Selenium)
- **Windows / macOS / Linux**

### Установка зависимостей

```bash
pip install -r requirements.txt
```

Основные зависимости:
- `selenium` - для работы с браузером
- `webdriver-manager` - автоматическая установка ChromeDriver
- `requests` - для скачивания изображений
- `Pillow` - для работы с изображениями
- `tkinter` - GUI (обычно входит в Python)
- `PySide6` - нативный GUI для macOS (fallback, если Tk недоступен)
- `win10toast` - уведомления Windows (опционально)

## Установка

1. Скачайте или клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите программу:
   - универсально: `python pinterest_gui.py`
   - macOS (Qt-версия): `python pinterest_gui_mac.py`

## Использование

### Базовое использование

1. **Запустите программу**: `python pinterest_gui.py` (или `python pinterest_gui_mac.py` на macOS)
2. **Введите URL доски Pinterest** в поле "URL доски"
3. **Настройте параметры** (опционально):
   - Количество изображений (0 = все)
   - Папка для сохранения
   - Качество изображений
4. **Нажмите "Запустить"**

### Добавление нескольких досок

1. Введите URL первой доски
2. Нажмите "Добавить в список"
3. Повторите для других досок
4. Настройте количество изображений для каждой доски (если нужно)
5. Нажмите "Запустить" для скачивания всех досок

### Настройка Upscale

1. Установите галочку "Включить upscale после скачивания"
2. Выберите параметры:
   - **Масштаб**: x2, x3 или x4
   - **Тип модели**: Авто, Фото или Аниме
   - **Размер тайла**: для настройки использования памяти (меньше = меньше VRAM)
   - **GPU**: номер видеокарты (0 = первая)
3. Программа автоматически запустит upscale после скачивания

**Важно**: Для работы upscale необходимо:
- Установить бинарник `realesrgan-ncnn-vulkan` (на Windows `realesrgan-ncnn-vulkan.exe`) в папку `upscale/tools/`
- Добавить модели в папку `upscale/tools/models/`

### Шаблоны имен файлов

Поддерживаемые переменные:
- `{index}` - номер изображения (1, 2, 3...)
- `{index04}` - номер с ведущими нулями (0001, 0002...)
- `{hash}` - короткий хэш URL (8 символов)
- `{url_hash}` - полный хэш URL

Примеры:
- `{index04}_{hash}.jpg` → `0001_a1b2c3d4.jpg`
- `pin_{index}.jpg` → `pin_1.jpg`

## Оценка времени

Программа автоматически:
- **Измеряет время** скачивания и upscale
- **Сохраняет статистику** в файл `timing_stats.json`
- **Оценивает оставшееся время** на основе предыдущих запусков
- **Показывает таймер** в реальном времени

При первом запуске оценка времени будет недоступна, но после нескольких скачиваний программа начнет показывать точные оценки.

## Решение проблем

### Ошибка: "Google Chrome не найден"

**Решение**: Установите Google Chrome с официального сайта: https://www.google.com/chrome/

### Ошибка: "ChromeDriver не найден"

**Решение**: Программа автоматически установит ChromeDriver при первом запуске. Если это не работает:
1. Убедитесь, что у вас есть доступ в интернет
2. Обновите Chrome до последней версии
3. Перезапустите программу

### Скачивается меньше изображений, чем запрошено

**Возможные причины**:
1. На доске меньше изображений, чем запрошено
2. Некоторые изображения не загружаются (проблемы с сетью)
3. Достигнут конец доски

**Решение**:
- Проверьте количество изображений на доске вручную
- Увеличьте задержку прокрутки в настройках
- Попробуйте скачать снова (программа пропустит уже скачанные)

### Программа зависает при скачивании

**Решение**:
1. Проверьте подключение к интернету
2. Увеличьте задержку скачивания в настройках
3. Уменьшите количество параллельных потоков (в коде)
4. Проверьте логи в консоли для диагностики

### Upscale не работает

**Проверьте**:
1. Установлен ли `realesrgan-ncnn-vulkan`/`realesrgan-ncnn-vulkan.exe` в `upscale/tools/`
2. Есть ли модели в `upscale/tools/models/`
3. Достаточно ли VRAM на видеокарте (уменьшите размер тайла)
4. Проверьте логи в консоли (они начинаются с `[UPSCALE]`)

**Решение**:
- Скачайте Real-ESRGAN с официального репозитория
- Добавьте модели (файлы `.param` и `.bin`)
- Уменьшите размер тайла до 100-150 при нехватке памяти

### Ошибка при скачивании изображений (403 Forbidden)

**Причина**: Pinterest блокирует некоторые запросы

**Решение**:
- Программа автоматически пробует несколько методов скачивания
- Если все методы не работают, попробуйте:
  - Войти в Pinterest в браузере Chrome перед запуском программы
  - Использовать VPN
  - Увеличить задержку между скачиваниями

### Изображения скачиваются в низком качестве

**Решение**:
- Убедитесь, что в настройках выбрано "Полное качество" (full)
- Проверьте, что на доске есть изображения в высоком разрешении

### Программа не находит изображения

**Возможные причины**:
1. Неправильный URL
2. Доска приватная или недоступна
3. Проблемы с загрузкой страницы

**Решение**:
- Проверьте URL в браузере
- Убедитесь, что доска публичная
- Увеличьте задержку прокрутки
- Проверьте логи в консоли

## Настройки

### Параметры скачивания

- **Задержка прокрутки**: время ожидания между прокрутками страницы (рекомендуется 2.0 сек)
- **Задержка скачивания**: время между скачиваниями изображений (рекомендуется 0.5 сек)
- **Качество изображений**: full (полное), medium (среднее), small (маленькое)

### Параметры Upscale

- **Масштаб**: x2, x3, x4 (рекомендуется x3)
- **Тип модели**: 
  - Авто - автоматический выбор
  - Фото - для фотографий
  - Аниме - для аниме/иллюстраций
- **Размер тайла**: 50-500 (меньше = меньше VRAM, но медленнее)
- **GPU**: номер видеокарты (0 = первая)

## Логирование

Программа выводит подробные логи:
- В GUI окне (вкладка "Логи")
- В консоли (для upscale - с префиксом `[UPSCALE]`)

При проблемах проверяйте логи для диагностики.

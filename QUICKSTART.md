# Быстрый старт - Pinterest Image Downloader GUI

## Установка

### macOS

**Как обычная программа.** Соберите и установите `Pinterest Downloader.app` в «Программы» — дальше
запуск из Launchpad или Spotlight, без терминала:

```bash
./packaging/build_macos.sh --install
```

Сборка кладёт внутрь Python, все библиотеки и Real-ESRGAN, а в конце сама проверяет себя (`--self-test`).
Данные программы — в `~/Library/Application Support/Pinterest Downloader`; при первом запуске туда
переносятся очередь, история и настройки из папки проекта, а логин из `.env` — в Связку ключей.
Картинки продолжают сохраняться в прежнюю папку.

**Из исходников.** На Mac используется нативный интерфейс на Qt (PySide6) — подходит любой Python 3.9+, включая встроенный:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python pinterest_gui.py        # или python pinterest_gui_mac.py — это одно и то же окно
```

Почему не Tk: Python из **Xcode Command Line Tools** идёт со старым **Tk 8.5**, который на новых macOS либо падает при старте, либо показывает пустое белое окно. Поэтому `pinterest_gui.py` на Mac сразу открывает Qt-интерфейс. Старый Tk-интерфейс можно включить вручную (`PIN_DOWNLOADER_TK=1`), но только с Tk 8.6+ (Python с python.org или Homebrew).

Полезные сочетания клавиш: ⌘L — поле ссылки, ⌘⇧V — добавить ссылки из буфера, ⌘↩ — скачать, ⌘. — остановить, ⌘1…⌘5 — разделы, ⌘, — настройки. Ссылку можно просто перетащить из браузера в окно.

Очередь досок: порядок меняется перетаскиванием за «⠿» слева, у каждой доски свой лимит, прогресс и скорость. Кнопка справа в строке: ▶ — скачать только эту доску (или следующей, если загрузка уже идёт), ⏸ — пауза, ⟳ — повторить после ошибки, ⋯ — меню. Доски можно добавлять прямо во время загрузки — они скачаются в том же запуске. Под полем ссылки — недавние доски из истории, добавляются одним нажатием.

### Все платформы

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python pinterest_gui.py
```

## Первое использование

1. Введите URL доски Pinterest (например: `https://ru.pinterest.com/username/board-name/`)
2. Укажите количество изображений (например: `10` для первых 10 изображений, или `0` для всех)
3. Выберите папку для сохранения
4. Нажмите "Начать скачивание"

## Все 12 функций приложения

1. ✅ **Ограничение количества** - укажите сколько изображений скачать
2. ✅ **Выбор папки** - удобный выбор через диалог
3. ✅ **Прогресс-бар** - визуальный прогресс скачивания
4. ✅ **Лог действий** - подробный лог с временными метками
5. ✅ **Фильтр по размеру** - скачивайте только нужные размеры (в МБ)
6. ✅ **Выбор качества** - полный размер / средний / маленький
7. ✅ **Пауза/возобновление** - контроль процесса скачивания
8. ✅ **История** - сохранение всех скачанных досок
9. ✅ **Автопереименование** - понятные имена файлов
10. ✅ **Экспорт URL** - сохранение списка всех URL
11. ✅ **Настройки задержек** - контроль скорости работы
12. ✅ **Предпросмотр** - миниатюры найденных изображений

## Примеры использования

### Скачать первые 10 изображений
- Количество: `10`
- Качество: `Полный размер`
- Нажать "Начать скачивание"

### Скачать только большие файлы
- Количество: `0` (все)
- Размер файла: От `1` до `1000` МБ
- Начать скачивание

### Быстрое скачивание
- Задержка прокрутки: `1.0` сек
- Задержка скачивания: `0.1` сек
- Начать скачивание

### Экономия места
- Качество: `Средний` или `Маленький`
- Начать скачивание

## Советы

- Используйте историю для быстрого доступа к ранее скачанным доскам
- Экспортируйте URL для резервного копирования
- Предпросмотр показывает первые 50 найденных изображений
- Приложение автоматически останавливается перед разделом "Похожие пины"
